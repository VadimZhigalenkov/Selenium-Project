# SeleniumProject

Проект автоматизации UI-тестирования сайта
[SauceDemo](https://www.saucedemo.com/) на Python с использованием
Selenium WebDriver, pytest, паттерна Page Object Model (POM), отчётности
Allure и библиотеки Faker.

## Возможности

-   Авторизация под стандартной тестовой учётной записью SauceDemo.
-   Проверка перехода по ссылке About.
-   Автоматизация покупки трёх демонстрационных товаров:
    -   Sauce Labs Backpack
    -   Sauce Labs Bike Light
    -   Sauce Labs Bolt T-Shirt
-   Использование Page Object Model для отделения локаторов и действий
    со страницами от сценариев тестирования.
-   Ожидание доступности интерактивных элементов с помощью явных
    ожиданий.
-   Добавление шагов Allure и запись логов выполнения.
-   Создание скриншота в конце успешного сценария оформления заказа.

## Требования

-   Рекомендуется Python 3.10 или новее.
-   Установленный Google Chrome.
-   Совместимый ChromeDriver. В современных версиях Selenium драйвер
    может устанавливаться автоматически, если это позволяет окружение.
-   Зависимости из файла `requirements.txt`.

## Установка

1.  Клонируйте репозиторий или распакуйте архив.

2.  Откройте терминал в каталоге проекта.

3.  Создайте и активируйте виртуальное окружение:

    ``` bash
    python -m venv .venv
    ```

    Windows:

    ``` powershell
    .venv\Scripts\Activate.ps1
    ```

    macOS/Linux:

    ``` bash
    source .venv/bin/activate
    ```

4.  Установите зависимости:

    ``` bash
    python -m pip install --upgrade pip
    pip install -r requirements.txt
    ```

## Запуск тестов

Запустить весь набор тестов:

``` bash
pytest
```

Запустить отдельный модуль:

``` bash
pytest tests/test_about_link.py
pytest tests/test_buy_product.py
```

В `conftest.py` браузер настроен на запуск в headless-режиме. После
каждого теста фикстура закрывает браузер.

## Отчёты Allure

В тестах используются шаги `allure-pytest`. Чтобы сохранить результаты
Allure:

``` bash
pytest --alluredir=allure-results
```

Если установлен Allure Commandline, сформируйте и откройте отчёт
командой:

``` bash
allure serve allure-results
```

## Примечания по настройке

-   Учётные данные для тестов указаны в `pages/login_page.py` для
    публичного демонстрационного сайта SauceDemo.
-   Данные покупателя генерируются с помощью Faker в
    `pages/client_information_page.py`.
-   В `base/base_class.py` скриншоты сохраняются по жёстко заданному
    пути Windows. Для запуска на другом компьютере замените его на путь
    относительно проекта или создайте нужный каталог.
-   В `utilities/logger.py` также указан жёстко заданный путь Windows
    для логов. Замените его на существующий путь и убедитесь, что
    каталог для логов создан.
-   В логгере указано `encoding='utf=8'`; вероятно, это опечатка. Обычно
    следует использовать `encoding='utf-8'`.
-   Каталоги `screen/` и `logs/` должны существовать, если текущая
    конфигурация записывает в них файлы.
-   Тесты выполняют демонстрационное оформление заказа на SauceDemo и не
    обрабатывают реальные платежи.

## Решение проблем

-   **Chrome не запускается:** проверьте установку Chrome и возможность
    Selenium получить совместимый драйвер.
-   **Истекает время ожидания элементов:** проверьте подключение к
    интернету и доступность сайта SauceDemo.
-   **Ошибка при сохранении логов или скриншотов:** замените жёстко
    заданные пути на существующие каталоги на вашем компьютере.
-   **Отчёт Allure пустой:** запустите pytest с параметром
    `--alluredir=allure-results` и убедитесь, что тесты завершились.
